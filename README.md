# 브루 다이얼 (Brew Dial)

그라인더·드리퍼·배전도를 고르면 유명 바리스타 레시피를 **내 그라인더 클릭수**로 환산해 주고,
추출 타이머에 맞춰 **물 붓는 모양(위/옆 단면)** 을 보여주는 단일 HTML 브루잉 콘솔.

- 메인 파일: [`brew-dial.html`](brew-dial.html) — 의존성 없음, 브라우저로 열면 바로 동작
- 레시피 40종 (V60 · 칼리타 웨이브 · 오리가미 · 코노 · 융드립 · 스위치 · 클레버 · 케멕스 · 프렌치프레스 · 에어로프레스)
- 그라인더 환산: 코만단테 MK4 · 밀랩 M01 · 1Zpresso K-Ultra · 페모북 A2 · EK43s · 타임모어 C3 · 바라짜 엔코어 · 직접 보정
- 배전도/가공방식 보정은 각 레시피의 **기준 배전도**를 기준으로 계산

레시피 수치는 공개 자료를 정리한 것으로, 표시값은 출발점으로 쓰고 맛으로 마무리하세요.
