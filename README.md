# Coffeere

커피 레시피와 원두를 기록하고, 그라인더 분쇄도를 서로 환산하는 모바일 웹 앱입니다.
의존성 없는 정적 파일이라 브라우저로 열면 바로 동작하고, 모든 기록은 그 기기의 브라우저에만 저장됩니다.

**👉 https://cos2104.github.io/coffeere**

홈 화면에 추가하면 주소창 없는 전체 화면으로 실행됩니다 (PWA).

## 화면 구성

하단 4개 탭으로 이동합니다.

| 탭 | 하는 일 |
|---|---|
| **레시피** | **내 레시피**(검색·필터·정렬, 추가/편집, **추출 타이머**) 와 **유명 레시피**(39종 라이브러리) 를 위쪽에서 전환 |
| **원두** | 원두 목록 · 검색 · 로스팅 레벨 필터 · 즐겨찾기/소진 필터, 원두 추가/편집 |
| **변환** | 그라인더 ↔ 그라인더 분쇄도 환산 |
| **설정** | 보유 그라인더 · 보유 드리퍼 선택, 데이터 백업/복원/초기화 |

### 유명 레시피 39종

레시피 탭 위쪽의 **유명 레시피** 를 누르면 2026 월드 브루어스컵 우승작(나스 자파르), 테츠 카스야 4:6 메소드, 제임스 호프만 얼티밋 V60,
오닉스 오스모틱 플로우 같은 공개 레시피 39종이 나옵니다.

- 목록에서 바로 **내 그라인더 클릭수** 로 환산된 분쇄도를 보여줍니다
- 상세에서 **원두량을 바꾸면 물·푸어링 단계가 전부 따라옵니다**
- 각 레시피의 **기준 배전도**(이 레시피가 설계된 배전도)를 함께 표시하고, 필터로도 쓸 수 있습니다
- 단계별 붓는 방식, 바리스타의 팁, 출처가 그대로 들어 있습니다
- **내 레시피로 담기** 를 누르면 그 순간의 원두량·그라인더 기준으로 복사되어, 이후 내 것으로 고쳐 쓸 수 있습니다

### 새 레시피
추출 방식(브루잉 · 에스프레소 · 침출식 · 기타 → 기구 선택) → 기본 정보(이름, 원두) →
추출 파라미터(원두량 · 물 · 추출 시간 · 수온 · 분쇄도) → 푸어링 스텝 → 평점 → 메모.

기구를 고르면 그 기구의 기본값과 푸어링 스텝이 자동으로 채워집니다.
물의 양을 바꾸면 푸어링 스텝이 비율대로 따라 조정되고, 스텝 합계는 항상 총 물의 양과 맞춰집니다.

### 새 원두
기본 정보(원두명 · 로스터리) → 원산지(국가 · 지역 · 농장 · 품종 · 재배 고도) →
로스팅/가공(로스팅 레벨 · 가공 방식 · 로스팅 날짜) → 향미 노트 + 노트 색상 → 평점 → 메모.

### 추출 타이머
레시피 상세에서 시작하면 푸어링 스텝을 따라가며 지금 부을 양과 누적량을 보여주고,
단계가 바뀔 때와 목표 시간에 알림음이 울립니다.

## 분쇄도 환산

입자 크기(μm)를 중간값으로 두고 양쪽 그라인더의 환산 곡선을 보간합니다.
수록 그라인더: 코만단테 C40(MK4) · 1Zpresso K-Ultra · 페모북 A2 · 밀랩 M01 ·
타임모어 C3 · 바라짜 엔코어 · EK43s.

환산 곡선은 공식 사양과 커뮤니티 실측 자료를 정리한 값입니다.
버·개체차·원두 상태에 따라 실제 값은 1–2클릭 달라질 수 있으니 **표시값은 출발점으로 쓰고 맛으로 마무리하세요.**

## 파일 구조

```
index.html              앱 셸
manifest.webmanifest    PWA 설정
assets/app.css          스타일 (다크 테마)
assets/icons.js         인라인 SVG 아이콘
assets/data.js          그라인더 환산 곡선 · 추출 기구 · 로스팅/가공 기준 데이터
assets/library.js       유명 레시피 39종 + 내 기준 환산 어댑터
assets/app.js           저장소 · 4개 탭 화면
assets/sheets.js        시트(모달) 시스템 · 선택기
assets/editor.js        레시피 / 원두 편집 화면
assets/libview.js       유명 레시피 상세 화면
assets/detail.js        레시피·원두 상세 · 추출 타이머
```

## 데이터

내 레시피와 원두 기록은 브라우저 `localStorage`(`coffeere.v3`)에 저장됩니다.
유명 레시피 39종은 앱에 포함된 고정 데이터라 따로 저장되지 않습니다. 서버로 전송되는 정보는 없습니다.
기기를 옮기거나 브라우저 데이터를 지우기 전에 **설정 → 백업 파일 내보내기**로 JSON을 저장해 두세요.
